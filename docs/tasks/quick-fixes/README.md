# Quick Fix Logs

This folder stores lightweight records for single-purpose, isolated, low-risk fixes that qualify for `.agents/skills/quick-fix/SKILL.md` instead of a full task plan folder.

Use one date file per day: `YYYY-MM-DD.md`.

Each entry must record the request, pre-flight readiness result, changed files, verification result, documentation update, and whether escalation to `plan-task` is needed. Do not use live progress checkboxes in quick-fix logs.
